# Rosea 🌹

An ASCII-art love note that runs in the browser.

- A cheeky intro: an ASCII butt farts out a bouquet 💨🌹
- A 3D bouquet of ASCII roses that slowly blooms under a twinkling ASCII night sky
- "I love you" typed out underneath, and tap anywhere for a burst of ASCII hearts
- Scroll down for a purple ASCII envelope that opens to a two-page love letter

Everything is in a single file, `index.html`. No build step, no dependencies.

## Hosting with GitHub Pages

1. Go to **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source** to *Deploy from a branch*.
3. Choose the `main` branch and the `/ (root)` folder, then save.
4. After a minute the site will be live at `https://nerofuri.github.io/Rosea/`.

## Editing the text

- The message under the bouquet: search `let message=` in `index.html`.
- The letter pages: search `DEFAULT_LETTER` (page 1) and `PAGE2` (page 2).
